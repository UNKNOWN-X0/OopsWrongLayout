How it works

Each character is traced back to the physical key that produced it in the layout you typed in, then read off that same key in the layout you meant. No dictionary and no guessing, the same trick tools like Punto Switcher use. On the key map, each key shows its typed as character top-left and its should have been character bottom-right.

Known limits

Thai and German mappings cover the common keys; a few rare symbol keys may not be perfectly accurate. Hebrew has no letter case, so capitalization is lost on a round trip through it.
